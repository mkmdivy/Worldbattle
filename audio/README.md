# 목소리 팩 (성우 녹음)

이 폴더에 녹음 파일과 `voices.json`을 넣으면, 게임이 브라우저 음성 대신 그 녹음을 재생합니다.
녹음은 분대가 함께 외치는 느낌이 나도록 살짝 겹치고 잔향을 넣어 재생됩니다(대기실 "듣기"는 원음 그대로).
`voices.json`이 없으면 기기에 있는 가장 자연스러운 음성(Natural·Neural·Premium 순)으로 읽습니다.

## 넣는 방법
1. 대사는 [LINES.md](LINES.md)에 나라 코드별로 있습니다. 위쪽이 자주 걸리는 나라입니다.
2. 파일 이름은 `코드.mp3` 또는 같은 대사의 여러 테이크를 `코드_2.mp3`처럼 붙입니다. (mp3·ogg·wav 모두 가능)
3. `voices.json`에 코드 → 파일 목록을 적습니다. 여러 개면 매번 무작위로 하나를 고릅니다.

```json
{
  "KR": ["KR.mp3", "KR_2.mp3"],
  "JP": ["JP.mp3"],
  "US": ["US.mp3"]
}
```

## 녹음 팁
- 한마디는 1초 안팎, 앞뒤 무음은 최대한 잘라 주세요.
- 전투 함성 톤으로, 너무 크게 지르기보다 힘 있게 끊어 말하는 편이 반복해서 들어도 덜 피곤합니다.
- 44.1kHz 모노, -3dB 정도로 맞추면 됩니다. 파일 하나는 20~40KB면 충분합니다.

아티팩트(claude.ai)에서도 쓰려면 이 폴더의 파일을 아티팩트에 함께 게시해야 합니다.
